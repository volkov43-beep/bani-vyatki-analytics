# Bani Vyatki Analytics

Тестовый аналитический дашборд компании «Бани Вятки». Репозиторий и GitHub Pages сейчас **публичные**, поэтому в исходниках разрешены только обезличенные демонстрационные данные.

Рабочая демонстрационная ссылка: https://volkov43-beep.github.io/bani-vyatki-analytics/

- [Раздел 01 — Общие показатели](https://volkov43-beep.github.io/bani-vyatki-analytics/)
- [Раздел 02 — Источники обращений](https://volkov43-beep.github.io/bani-vyatki-analytics/sources.html)
- [Раздел 03 — Продажи и воронка](https://volkov43-beep.github.io/bani-vyatki-analytics/sales.html)
- **Раздел 04 — Результативность менеджеров** — в отдельном PR на согласовании; после merge: https://volkov43-beep.github.io/bani-vyatki-analytics/managers.html

Сначала изменения создаются в новой ветке через PR, после согласования объединяются в main. GitHub Pages публикует уже объединённые изменения.

## Обновлённые показатели сентября

Общий итог — **13 договоров, 5 643 000 ₽ выручки по договорам**, **1 240 000 ₽ общей маржи**. Обращений — **222**, целевых — **122**. Источники договоров: Авито — 8, ВКонтакте — 3, звонки — 2.

Раздел 01: два прогноза компании (реалистичный/оптимистичный), план/факт выручки и маржи, отдельная экономика Авито. [Методика](docs/metrics.md).

Раздел 02: ежедневные обращения по источникам, качество, причины исключения. [Методика](docs/sources-september-2026.md).

Раздел 03: динамика договоров и выручки, источники продаж, текущие стадии сентябрьской когорты. [Методика](docs/sales-funnel.md). Обращения, созданные в сентябре, и договоры, заключённые в сентябре, — **разные группы сделок**.

Раздел 04: показатели сотрудников, **полное распределение всех 13 договоров по менеджерам**, график выручки по людям, подробная обезличенная таблица договоров и отдельная колонка **«Маржа по сделке, ₽»**. В сентябре нет значений маржи по каждой сделке, поэтому колонка пока пуста. [Методика](docs/managers.md).

## В дальнейшем

Раздел 05 — цикл сделки; раздел 06 — маркетинговые расходы. Затем PHP 8.5, MySQL, интеграция с Битрикс24 через REST API (только чтение) и закрытый доступ на https://analyticsbanivyatki.vermarkter.ru.

### Безопасность

**Нельзя загружать в публичный GitHub или Pages** клиентские имена, телефоны, электронную почту, комментарии с персональными данными, реальные ID сделок, токены, адреса входящих вебхуков и другие секреты. Менеджеры будут заполнять маржу в Битрикс24 после настройки соответствующего поля, а защищённое серверное приложение будет получать её и рассчитывать сводные показатели. GitHub Pages не используется как база данных или защищённая административная панель.

**Не объединять PR без подтверждения пользователя.**
