**Нельзя загружать в публичный GitHub или Pages** клиентские имена, телефоны, электронную почту, комментарии с персональными данными, реальные ID сделок, токены, адреса входящих вебхуков и другие секреты. ## Раздел 07 — «Авито: объявления»

Новая страница `avito.html` — статистика объявлений из **Avito Pro** по дням. Раздел **отдельный и в общие итоги не входит**: обращения и продажи по-прежнему считаются в CRM (разделы 01–05). Задача раздела — видеть, как повлиять на количество обращений с Авито.

- **Месяц в цифрах:** просмотры, контакты (чат / телефон), конверсия в контакт, затраты (деньги + бонусы), цена контакта; сравнение с прошлым месяцем по среднему за день.
- **По дням:** три графика с общей шкалой — просмотры, контакты, затраты; незагруженные дни заштрихованы; таблица по дням.
- **По месяцам:** средние за день, чтобы незаконченный месяц сравнивался честно.
- **Объявления месяца:** группы «Работают / Смотрят, но не пишут / Пишут, но мало видят / Слабые / Мало просмотров», график «просмотры в день × конверсия», таблица с мини-графиком по дням, на телефоне — карточки.

Данные: сентябрь 2026 (4 489 просмотров, 112 контактов, затраты 85 493 ₽), октябрь (7 491 просмотр, 115 контактов, 87 916 ₽) и 1–6 ноября. Июнь–август — после дневных выгрузок.

- Данные собираются скриптом `scripts/build-avito-data.py` из дневных выгрузок (сами выгрузки в репозиторий не кладутся); справочник названий — `data/avito-listings.csv`.
