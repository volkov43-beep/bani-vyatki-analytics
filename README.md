# Bani Vyatki Analytics

Приватный репозиторий управленческого дашборда компании «Бани Вятки».

Рабочие изменения предлагаются через отдельные ветки и pull request. Публикация на `analyticsbanivyatki.vermarkter.ru`, интеграция с Битрикс24 и доступ по паролю выполняются позднее, после согласования.

**Без секретов и персональных данных клиентов в Git.**
