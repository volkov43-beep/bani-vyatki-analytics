# Раздел 07 «Авито» — регламент обновления

Методика показателей — [docs/avito.md](avito.md).

| --- | --- | --- |
| 1. Выгрузить дневные файлы за прошедшие дни | маркетолог | раз в неделю (по понедельникам) и до **3-го числа** за прошедший месяц |
| 2. Добавить новые объявления в справочник, пересобрать данные, сверить, открыть PR | Claude | в день получения файлов |

## Что выгружать

Avito Pro → «Статистика объявлений» → Excel, **период — один день** (с 1 по 1, со 2 по 2 и т. д.). Один файл = один день, дата — в конце имени файла (как выгружает Авито).

- Выгружать **после окончания дня**: статистика за текущий день неполная.
- Если в настройках выгрузки появятся колонки «Номер объявления» и «Название» — включить: сопоставление станет точным.
- Удобно присылать пачкой (zip) за неделю или за месяц.

Исходные файлы **в репозиторий не кладутся**. В публичный `avito-data.js` попадают только итоги по дням и объявлениям.

## Новые объявления

Сборка останавливается, если в выгрузке есть объявление, которого нет в `data/avito-listings.csv`, и пишет его ключ (город, адрес, категория, цена, дата первой публикации). Нужно:

1. Узнать название (скриншот списка объявлений в Avito Pro или текст от маркетолога).
2. Добавить строку в `data/avito-listings.csv` со следующим свободным `id` и `Статус = ok` (или `уточнить`, если названия пока нет).
3. Если у старого объявления изменилась цена — добавить новую строку с тем же названием и новым `id`.

## Сборка и проверки

```bash
# новые дни дописываются к уже опубликованным данным — старые выгрузки не нужны
python3 scripts/build-avito-data.py --base avito-data.js --exports ПАПКА_С_НОВЫМИ_ДНЯМИ --listings data/avito-listings.csv --out avito-data.js
# полная пересборка (если есть все дневные выгрузки с 01.08.2026)
python3 scripts/build-avito-data.py --exports ПАПКА_С_ВЫГРУЗКАМИ --listings data/avito-listings.csv --out avito-data.js
node scripts/check-responsive-foundation.mjs
node scripts/check-navigation.mjs
node scripts/check-public-dashboard.mjs
python scripts/test-avito-browser.py
```

С `--base` сборка останавливается, если день уже есть в данных, если между старыми и новыми днями пропуск или если справочник изменён не дописыванием в конец.

При добавлении месяца или дней: утверждённые итоги нового месяца дописываются в `scripts/check-responsive-foundation.mjs` и в `EXPECTED` в `scripts/test-avito-browser.py`. PR — из ветки `feature/avito-data-ГГГГ-ММ`, с таблицей новых значений и итогами сверки. **Не объединять без одобрения владельца.**

Сверка перед PR:
- сумма дневных файлов за месяц = выгрузка Avito Pro за тот же месяц одним файлом (если есть);
- у каждого дня одна выгрузка, без пропусков внутри загруженного периода;
- новые объявления добавлены в справочник, «близнецы» отмечены.

## Дальше

После запуска серверной версии (PHP, MySQL, закрытый доступ) статистику можно получать автоматически через API Авито (статистика объявлений по дням: просмотры, контакты, избранное). API отдаёт данные не глубже примерно 270 дней назад — поэтому историю стоит сохранять у себя. Токены хранятся на сервере и никогда не попадают в GitHub.
