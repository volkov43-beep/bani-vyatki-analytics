# Раздел 05 «Цикл сделки» — методика

## Что измеряем

**Цикл продажи** = календарная дата заключения договора − дата поступления обращения / дата создания сделки в CRM. Время внутри отдельных стадий пока не измеряется.

Из 13 договоров сентября:
- Для **10** датой начала служит графа «Заявка» в маркетинговом отчёте за сентябрь 2026 (разделы 8–9).
- Для **3** добавленных договоров дата начала установлена по полю **«Дата создания»** соответствующей сделки из XLS-выгрузки Битрикс24. Совпадение подтверждено по ответственному, источнику, цене и дате заключения. Создание сделки — возможный прокси первого обращения, но **не обязательно самый первый фактический контакт**.

В публичном приложении данные покупателей и ID карточек отсутствуют; хранится обезличенная привязка по дате договора, менеджеру, источнику и сумме.

## Все 13 длительностей

В календарных днях:
`9, 0, 23, 2, 2, 18, 6, 17, 11, 6, 2, 44, 10`.

После сортировки:
`0, 2, 2, 2, 6, 6, 9, 10, 11, 17, 18, 23, 44`.

- **Среднее:** 150 / 13 = **11,538… ≈ 11,5 дня**.
- **Медиана:** **9 дней**.
- **Быстрые (0–7 дней):** **6 из 13 = 46,2%**.
- **Средние (8–30 дней):** **6 из 13 = 46,2%**.
- **Долгие (от 31 дня):** **1 из 13 = 7,7%**.
- **Минимум:** 0 дней. **Максимум:** 44 дня.
- **Полнота:** 13/13 договоров (100%) по датам отчёта или регистрации сделки в CRM.

Договоры по обращениям, датированным августом: **4 договора на 1 934 000 ₽**. Таким образом, месяц продажи и месяц привлечения часто различаются.

## Сравнение с июлем–августом 2026

По исходному маркетинговому отчёту за два месяца (13 договоров): среднее **7 дней**, медиана **4 дня**, быстрых **85%**.

В сентябре после уточнения всех 13 договоров: среднее **11,5 дня** (+4,5 дня относительно округлённого исторического среднего), медиана **9 дней**, быстрых **46,2%**.

Предыдущее значение «11,8 дня» и медиана «8 дней» относились только к **10 договорам**, указанным в исходном сентябрьском отчёте; после добавления трёх договоров использовать их как финальные сентябрьские показатели **нельзя**.

## Программная структура

- `cycle.html` — отдельная страница; ссылка из остальных разделов.
- `cycle.css` — корпоративное оформление и адаптация.
- `cycle-data.js` — даты начала, источник каждой даты и исторические агрегаты.
- `cycle.js` — вычисление средних, медиан, долей, фильтры по менеджеру/источнику, сортировка продаж.
- `managers-data.js` — существующая обезличенная выборка всех 13 договоров.

В интерфейсе показаны KPI, распределение по категориям длительности, динамика в сравнении с июлем–августом, лента продаж, сравнение менеджеров и источников и таблица с датами **всех 13** договоров и происхождением даты начала.

## Важно для будущей интеграции Битрикс24

Полноценный цикл следует измерять по проверенному событию первого обращения и событию договора/аванса, а не просто по дате последнего изменения карточки. Подключив историю стадий, дополнительно рассчитаем:
- время от регистрации до первого контакта;
- время до квалификации и КЭВ;
- время от КЭВ до договора;
- «возраст» открытых сделок и задержки по стадиям.

На GitHub Pages пока только **публичный тестовый интерфейс со статическими обезличенными показателями**, без токенов, имён покупателей и доступа к CRM.
