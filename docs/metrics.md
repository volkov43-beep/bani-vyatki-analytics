## Формулы и ограничения

- Выполнение плана = факт / план × 100%. При превышении 100% полоса прогресса заполняется полностью, процент выводится точно.
- Изменение к августу = (сентябрь / август − 1) × 100%.
- Для затрат, стоимости заявки и стоимости продажи меньшее значение означает лучший результат, если остальные условия сопоставимы.
- «Выручка по договорам» — стоимость договоров, а не поступления на расчётный счёт.
- «Маржа, ₽» — представленная пользователем величина в рублях, а не маржинальность в процентах.
- В демоверсии нет API CRM, персональных данных клиентов, авторизации и автоматической синхронизации.
- Планы менеджеров и дневные графики добавляются позднее по согласованию.
