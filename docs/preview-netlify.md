# Закрытый визуальный предпросмотр через Netlify

## Зачем

GitHub хранит исходники, PR и историю изменений. Netlify автоматически собирает **только статический интерфейс** и предоставляет постоянную ссылку для просмотра в браузере. На GitHub Pages ничего публиковать не нужно. Рабочий домен `analyticsbanivyatki.vermarkter.ru` будет настроен позже на Beget.

## Защита — выполнить до публикации

Это корпоративные финансовые показатели. **Не делайте Netlify-проект публичным.** Доступ должен проверяться сервером Netlify, а не JavaScript-паролем в браузере.

- Перед импортом проверьте `Team settings → General → Visitor access → Default project visibility`, чтобы новые проекты по умолчанию были **Private**. Названия разделов могут незначительно отличаться.
- После создания проекта проверьте `Project configuration → General → Visitor access → Project visibility`: **Private**, scope **Production and previews**. При такой настройке посетителю потребуется войти в Netlify. На бесплатном тарифе обычно доступен только владелец команды.
- Не делитесь адресом до проверки доступа в приватном окне браузера, где нет авторизации Netlify.
- `X-Robots-Tag: noindex` лишь запрещает индексацию и **не заменяет** защиту авторизацией.

## Создание проекта

1. Откройте [Netlify](https://app.netlify.com/) под своей учётной записью.
2. `Add new project → Import an existing project → GitHub`.
3. Разрешите Netlify доступ к **только одному** репозиторию `volkov43-beep/bani-vyatki-analytics`.
4. Выберите `main` как production branch.
5. Настройки `netlify.toml` уже готовы: команда сборки собирает папку `preview-dist`, publish directory = `preview-dist`. Если Netlify просит вручную, используйте значения из `netlify.toml`.
6. Проверьте Private visibility, опубликуйте тестовую версию и скопируйте фактический адрес `https://<присвоенное-имя>.netlify.app/` из панели Netlify.
7. Проверьте, что дашборд открылся после входа в Netlify, переключаются сценарии и отображаются фирменные изображения. Откройте URL в приватном окне: сначала должен быть запрос авторизации.

Для следующих PR Netlify может автоматически показывать Deploy Previews. **Важно**, чтобы они тоже были Private. Изменения, попавшие в `main`, обновляют постоянный URL.

## Что публикуется

Команда сборки копирует исключительно `index.html`, `styles.css`, `app.js` и `assets/` в `preview-dist`. README, внутренние документы и исходные файлы из других путей в опубликованный пакет не попадают.

Это лишь **визуальный прототип** со статическими агрегатами. Здесь нет доступа к CRM, PHP, MySQL, webhooks, паролей, персональных данных клиентов, оплаты или финансовых операций.

## Будущий переход на Beget

На Beget будет развернута отдельная защищённая система на PHP/MySQL и подключен read-only REST API Битрикс24. Публичный Netlify-домен не должен использоваться для серверной CRM-интеграции. Разработку и согласование продолжаем через GitHub и PR.
