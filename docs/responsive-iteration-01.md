## Что сделано в итерации 01

1. Добавлен **design-system.css**: единый источник семантических цветов, бренда, типографики, размеров контейнера, полей, ширины сайдбара, радиусов, интервалов, фокуса и будущих доступных цветовых ролей.
2. Сохранены предыдущие CSS-переменные (**--forest, --gold, --cream, --panel** и другие) как совместимые алиасы. Это позволяет не переписывать все пять страниц одновременно.
3. Файл подключён **первым** в каждом из пяти HTML-документов: затем styles.css и CSS страницы.
4. Общая оболочка в styles.css теперь использует токены вместо повторяющихся числовых значений. В sources.css повторяющиеся размеры оболочки также переведены на те же токены, не меняя их численного значения.
5. Стили всех четырёх тематических модулей используют общие переменные **максимальной ширины**, **горизонтальных полей** и подходящей фоновой поверхности.
6. Согласован главный компактный порог 1460 px вместо 1450 в трёх модулях; мобильный порог источников 720 px вместо 710. Остальные пороги внутри сложных графиков пока намеренно сохранены для дальнейших итераций.
7. Добавлены **опциональные CSS-помощники**, которые не меняют автоматически старую разметку: bv-scroll-region, bv-visually-hidden, bv-num, bv-wrap-anywhere, bv-focusable, bv-touch-target.
8. Добавлен **беззависимый скрипт проверки** scripts/check-responsive-foundation.mjs и workflow CI, который запускает проверки структуры, синтаксиса JS и неизменности сентябрьских KPI.

Серверная часть, данные из Bitrix, логика расчётов и содержимое графиков не изменены.

## Контракт адаптивной оболочки

CSS-переменные нельзя использовать непосредственно в условиях @media, поэтому ширины фиксируются в документации и CSS, а не притворяются «работающими CSS-токенами медиазапросов».

| Режим | Ширина CSS px | Текущая оболочка | Следующий шаг |
| --- | --- | --- | --- |
| Wide desktop | от 1461 | Сайдбар 240 px, поле 36 px | Сохранить десктопный дизайн |
| Compact desktop | 1141–1460 | Сайдбар 215 px, поле 26 px | Уточнить плотность карточек |
| Tablet / rail | 721–1140 | Сайдбар 70 px с иконками | Понятные названия разделов и доступная навигация (итерация 02) |
| Mobile shell | 391–720 | Верхняя шапка, меню пока скрыто | Реальное мобильное меню (итерация 02) |
| Narrow mobile | 320–390 | KPI перестраиваются по своим CSS правилам | Проверка узких экранов в итерациях 03–07 |

**Исключения:** график/таблица может менять сетку раньше, если содержимое не помещается. Это отдельно проверяемое исключение, а не новая альтернативная оболочка. Итерация 01 не обещает, что все индивидуальные сетки уже приведены к одной матрице.

## Контраст, типографика, цели указателя

Новая роль --bv-color-secondary-ink: #536a59 на светлой поверхности #fffefb даёт ~5,83:1; она предназначена для замены избыточно светлых подписей в итерациях 03–07. Пока старые цвета сохраняются для отсутствия массовой незапрошенной переделки.

Для дальнейших страниц:
- обычный текст ≥4,5:1, крупный ≥3:1; значимые нетекстовые границы по WCAG 2.2 1.4.11;
- новые подписи не проектируем в 8–10 px — целевой минимум обычной вспомогательной информации 12 px, корректируется для плотных таблиц только с проверкой;
- важные элементы управления планируем **от 44×44 CSS px**, принимая во внимание нормативные исключения WCAG;
- фокус заметен на всех подложках; JavaScript-переключатели доступны с клавиатуры;
- при prefers-reduced-motion анимация не должна быть необходима для доступа к данным;
- кнопки и ссылки различаются семантически.

## Регрессионные проверки и условия допуска

### Машинные проверки (включены)

Команда из корня репозитория:

    node scripts/check-responsive-foundation.mjs

Скрипт проверяет:
- значения ключевых дизайн-токенов и контраст нового базового вторичного текста;
- совместимость старых алиасов, отсутствие неизвестных --bv CSS переменных;
- подключение нового CSS **на всех 5 страницах**, порядок подключения, сохранение ссылок навигации;
- сохранение ширин/полей/медиа-порогов оболочки;
- контрольные сентябрьские агрегаты: 13 договоров, 5 643 000 ₽ выручки, 1 240 000 ₽ общей маржи, 222 обращения, 122 целевых, 13 дат сделки;
- JS синтаксис через node --check в GitHub Actions.

Зелёный CI не подтверждает фактическую читаемость или расположение элементов в браузере.

### Браузерная матрица (выполняется последовательно в итерациях 02–08)

- **Ширины:** 320, 360, 390, 768, 1024, 1440, 1920 CSS px.
- **Увеличение:** 200% текста / масштаб, а также пользовательские межстрочные интервалы.
- **Сценарии:** длинный текст, низкая высота, прямой URL раздела, фильтры, клавиатура, hover/focus, уменьшение движения.
- **Таблицы:** внутренний скролл или структурная мобильная альтернатива. Общая горизонтальная прокрутка страницы недопустима, кроме обоснованных исключений.
- **Визуальные доказательства:** 360/768/1440 в каждой итерации + остальные размеры по матрице, с указанием версии кода и среды.
- **Автоматизация:** Playwright или эквивалент для скриншотов/действий, ручной просмотр и подтверждение пользователем. Эмуляция не доказывает работу Safari на iPhone.
