# Адаптивная вёрстка · Итерация 02/08 — навигация и оболочка

**Проект:** Bani Vyatki Analytics · **Дата:** 28.10.2026 · **Статус:** PR на согласовании, без merge.

## Цель и границы

Привести **навигацию на пяти страницах** к единому поведению на телефоне, планшете и компьютере. Сохранить утверждённый внешний вид десктопной версии и аналитические расчёты без изменений.

Основание NeuroLab Web: R01 (общая композиция), R02 (единая система токенов), R03 (ссылки и кнопки), R12 (фокус и reduced motion); Q4-06, Q4-07, Q4-09 и Q4-12 (reflow, клавиатура, доступность действий, визуальная приёмка).

## Что добавлено

1. **navigation.css** — адаптивная навигация поверх существующих стилей. Загружается после CSS каждого конкретного раздела.
2. **navigation.js** — единый обработчик мобильного меню. Никаких зависимостей, API или сбора пользовательских данных.
3. Пять страниц (`index.html`, `sources.html`, `sales.html`, `managers.html`, `cycle.html`) получили единые:
   - идентификатор навигации `bv-primary-nav`;
   - кнопку `bv-menu-toggle` с `aria-controls`, `aria-expanded`, доступным именем;
   - отдельную текстовую подпись иконки `bv-nav-label`;
   - `aria-label` и обозначение активной ссылки `aria-current="page"`;
   - отключённый пункт «Расходы» как текст, без фиктивной ссылки.
4. **scripts/check-navigation.mjs** — структурные и имитационные JS-тесты состояния меню.
5. **scripts/test-navigation-browser.py** и GitHub Actions — браузерные тесты Chromium: семь ширин, все пять страниц, клавиатура, отключённый JavaScript, реальные переходы между разделами.

## Поведение по ширинам

| Ширина CSS px | Оболочка | Навигация |
|---|---|---|
| 1461 и шире | Полный боковой сайдбар 240 px | Все названия доступны постоянно |
| 1141–1460 | Сайдбар 215 px | Полные названия |
| 721–1140 | Компактный сайдбар 70 px | Иконки; подписи на hover и фокусе клавиатуры; ссылки имеют aria-label |
| 320–720 | Горизонтальный верхний бренд-блок | Кнопка «Меню» 44 px и раскрываемый список с подписанными разделами |

Меню на телефоне **встроено в поток страницы**, не является модальным окном. Поэтому нет блокировки прокрутки или ловушки фокуса.

Управление с JavaScript: открыть/закрыть кнопкой; закрыть `Escape` и вернуть фокус; закрыть кликом вне меню или выбором раздела; при переходе через границу брейкпоинта состояние сбрасывается.

**Без JavaScript:** кнопка скрыта, а все ссылки меню открыты и доступны. Нет состояния, в котором интерактивная кнопка выглядит рабочей, но не отвечает на действие.

## Что проверяем

- Прямой вход на каждую из пяти HTML-страниц.
- Ровно одна активная ссылка и корректные подписи на всех экранах.
- Мобильное состояние: меню закрыто после инициализации, открывается кнопкой, закрывается Escape и кликом вне панели, корректное возвращение фокуса.
- Переключение раздела из мобильного меню.
- Планшет: иконки, видимый `focus-visible`, подписи на клавиатурном фокусе.
- Без JavaScript: список ссылок доступен.
- Смена viewport desktop → mobile → desktop не оставляет ложного `aria-expanded`.
- Контрольные размеры: **320, 360, 390, 768, 1024, 1440, 1920 CSS px**. В GitHub Actions сохраняются скриншоты части этих состояний.
- Отсутствие изменений финансовых значений проверяет уже существующий CI итерации №1.
