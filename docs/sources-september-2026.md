# Источники обращений — сентябрь 2026

**Статус:** тестовый раздел 02. Данные статические, без подключения к API Битрикс24. В `sources-data.js` сохранены **только агрегированные значения по дням и источникам**, без имён, контактов, ID сделок, телефонов и ссылок на клиентов.

## Источник данных

1. Выгрузка Битрикс24 «Лиды_CRM июнь-сентябрь 2026.xls», фактически HTML-экспорт **сделок**. Отобраны 222 сделки, у которых `Дата создания` находится в интервале 01.09.2026–30.09.2026.
2. Отчёт по маркетингу за сентябрь 2026: методика определения «целевой заявки» и финансовые итоги по источникам.
3. Позднейшее уточнение пользователя: договоры сентября — **13** (Авито 8, ВКонтакте 3, входящие звонки 2, прочие 0).

## Качество обращений

Для полного соответствия методике сентябрьского отчёта исключаем из целевых:
- `Спам.Различные предложения`;
- `Игнорит`;
- `не ответили после рассылки`.

Всё остальное в текущем **снимке** попадает в целевые, включая ещё не обработанные сделки. Поэтому это **предварительная классификация**, которая может измениться при повторной выгрузке.

## График по дням

- Столбцы строятся по **дате создания сделки**, а не по дате квалификации или сделки.
- Можно выбрать все обращения либо целевые по **доступному снимку CRM**; исторического качества на конец каждого дня в выгрузке нет.
- 14 сентября: 37 обращений, 36 с Авито. 28 сентября: 34 обращения, 31 с Авито. Вместе: 71/222 или около 32% обращений за месяц. Причину всплесков следует проверить, а не заранее приписывать рассылкам.
- Переключатель источника пересчитывает общие показатели и причины исключения. Диаграммы сравнения показывают все источники и выделяют выбранный.

## Важное ограничение: договоры

13 договоров за сентябрь распределены по каналам из отчёта с уточнениями пользователя; они могли быть заключены по заявкам августа и более ранних периодов. Поэтому отношение договоров за месяц к обращениям **того же месяца** не является полноценной когортной конверсией, и дашборд его пока не показывает.
